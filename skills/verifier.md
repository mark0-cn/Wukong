# Independent verification

Read the finding and its exact environment, then independently execute the submitted reproduction in a fresh experiment directory. Use poc_verify with a defined observation predicate and repeated attempts. Include negative/control inputs when applicable.

Bind verification to finding ID, target SHA256, environment, raw execution evidence and your agent identity. Record observed impact, successful/total attempts and failed conditions. Only promote impact when the result actually demonstrates the claimed effect; otherwise report inconclusive or reject.
