# Windows Worker 安装

[English](windows-worker.md) · 简体中文

[返回项目首页](../../README.zh-CN.md) · [使用指南](usage.zh-CN.md) · [在线安装与更新](online-install.zh-CN.md)

Windows Worker 卡片为一次性 Windows 分析虚拟机准备离线安装包，并在之后登记 Worker。它只提供两个主要操作：**生成安装包**和**导入安装结果**。此卡片不要求填写虚拟机地址、端口、用户名或私钥。

该卡片仅在 Windows x64 控制端显示。安装包在桌面应用内生成，无需安装 Python，也无需源码目录。它不包含 VMware 自动部署：虚拟机的创建、启动和修复由你完成。

<a id="windows-worker-prerequisites"></a>

## 前提条件

- 桌面发行版运行在 Windows x64 控制端。签名发行模板必须与控制端版本一致；其他版本的模板会被拒绝。
- 控制端能访问官方签名发行目录以下载模板，或者你已有匹配版本的模板 ZIP 可用于本地选择。模板很大（最大 8 GiB），下载可能需要数分钟。
- 一次性 Windows x64 虚拟机通过 IPv4 管理网络访问控制端，通常是主机专用或 VMnet 网卡。卡片只列出可用控制端网卡，并优先推荐 RFC 1918 地址。
- 生成的安装包内嵌只针对本控制端的官方离线 Worker 安装程序。不要替换其中的二进制文件，也不要把介质复制到无关控制端。

<a id="windows-worker-generate"></a>

## 生成安装包

1. 打开**工作区设置 → 分析环境**，找到 **Windows Worker** 卡片。
2. 选择**生成安装包**。
3. 可选填写环境名称。留空时使用后端默认名称：`Windows Worker` 加安装标识前 8 个字符。
4. 检查管理网络。只有一个可用 IPv4 网络时会自动选择；存在多个时请选择虚拟机可访问的网卡，推荐项默认选中。
5. 使用签名发行模板，或选择**已有下载好的模板 ZIP？**并指定与本版本匹配的本地模板文件。
6. 选择安装包保存位置并开始生成。

生成在后端分为三个阶段：下载模板、校验签名大小与 SHA-256、生成密封介质。卡片会显示不确定进度条、阶段顺序和已用时间，不显示虚假百分比。完成前请保持窗口打开。

生成完成后，卡片会显示安装包路径、SSH 端口、管理网络和安装步骤。安装包不包含控制端凭据，但它与本控制端及本次安装绑定；请按敏感文件保管。

<a id="windows-worker-install"></a>

## 在 Windows 虚拟机中安装

1. 将生成的 ZIP 复制到一次性 Windows 虚拟机并解压。
2. 双击解压介质中的 `WukongWorkerSetup.exe`，确认安装摘要并执行安装。
3. 安装完成后保存导出的 `connection.json` 安装结果。同一窗口会显示 SSH 主机指纹，请与下文说明的值核对。
4. 返回控制端。不要手工配置虚拟机地址或端口：校验只使用安装结果中记录的候选地址。

<a id="windows-worker-import"></a>

## 导入并校验安装结果

1. 选择**导入安装结果**，选择 `receipt_version: 2` 的 `connection.json`。如果原安装只生成了 v1 结果，请在新的一次性 Windows VM 中使用当前介质安装并导入新结果。
2. 卡片会显示文件中的 SSH 主机指纹。请与虚拟机安装窗口显示的指纹核对，并在确认框中输入虚拟机窗口的指纹。只有完全一致时导入按钮才可用；文件本身不能作为独立确认。
3. 可选修改环境名称。留空时沿用生成安装包时使用的名称。
4. 选择**导入并校验**。控制端只对保存的候选地址使用与后续分析相同的受管 SSH 通道和严格主机密钥固定进行校验，然后登记环境。卡片会变为可用（绿色），并显示已登记环境与地址。

环境名称之后可在**工作区设置 → 高级**中修改。改名不会改变安装标识、主机密钥或介质。

<a id="windows-worker-states"></a>

## 卡片状态与恢复

| 状态 | 含义 | 后续操作 |
| --- | --- | --- |
| 已生成安装包 | 安装包位于本控制端，但尚未导入安装结果。 | 在虚拟机中安装介质，然后导入安装结果。 |
| 等待连接 | 已导入安装结果，但保存的候选地址尚未通过受管 SSH 连接校验。 | 启动虚拟机并接好管理网络，然后选择**重试连接**。 |
| 可用 | 校验成功，环境已登记。 | 像其他已登记环境一样使用。 |

如果虚拟机地址变化，请在虚拟机中不带参数重新运行安装程序。它不会重装 Worker，只重新枚举当前网卡地址并保存最新的安装结果。请重新导入该文件，而不要重置 Worker。如果已登记 Worker 的主机密钥发生变化，导入会失败且不会替换现有连接。

每个安装项还会列出只读部署诊断：生成记录、恢复记录、已导入的安装结果回执和环境登记是已记录、缺失还是损坏，以及连接校验是尚未开始、未完成、已校验还是无法判断。损坏记录会被报告，但绝不会被删除或静默忽略；损坏或缺失的记录也绝不会显示为已校验。单个无法读取的生成记录不会隐藏可读的安装项，也不会覆盖任何内容；请在导入或部署前修复或移除损坏记录。

其他失败会显示后端详情和可操作提示：

- 主机密钥不匹配，或安装结果属于其他控制端/安装：导入被拒绝，不会覆盖任何内容。请在本控制端重新生成介质，并在虚拟机中安装该介质。
- 发行目录未发布介质模板：请选择由本版本构建的本地模板 ZIP。
- 未找到可用管理网络：连接虚拟机的主机专用或管理网卡，然后重新加载网络列表。

<a id="windows-worker-limits"></a>

## 限制与信任边界

- 卡片不会部署或恢复 VMware 虚拟机、快照或客体。请自行准备并清理一次性虚拟机。
- 校验范围限于安装结果中的候选地址，不会扫描管理网络。虚拟机未启动时会保持待处理状态，而不会猜测地址。
- 成功导入证明 Worker 身份及通过记录的主机密钥可达，但不证明虚拟机管理程序隔离或生产可用性；客体控制项和其余限制见 [Windows 组件说明](../../workers/windows/README.zh-CN.md)。
- 生成的介质针对本控制端且不含控制端凭据，但仍代表一个 Worker 被授权给本控制端。请按敏感文件保管；未经审查的安装尝试后应弃用虚拟机而不是重复使用。
