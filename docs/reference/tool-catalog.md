# Built-in tool catalog

English · [简体中文](tool-catalog.zh-CN.md)

Generated from the registry by `wukong tool-catalog`. Do not edit manually.

Rig provides native coordination tools `task`, `message`, `wait`; MCP tools depend on configuration. This table lists business tools, role boundaries and backend requirements. Actual model selections are also filtered by environment preflight; execution checks target identity, evidence, session ownership and current backend capabilities. Translated descriptions are documentation only and do not change the model protocol.

Active descendants must finish first. |
| `analysis_verify` | analyst / verifier | yes | controller | Verifier only: record an independent general-analysis verdict with expected and observed results, scope, counterexamples and verifier-owned evidence. Does not promote security impact. Records are immutable and appear in shared notes. |

| `emulate_run` | analyst / verifier | no | emulation | Bounded Unicorn emulation of the staged target from a start address: maps the ELF segments plus a stack, executes up to count instructions or until the PC reaches the until address (whichever first), and returns registers plus requested memory dumps (data_base64). Use init_regs for register preconditions and memory to inject bytes. The watchdog timeout bounds runaway loops; unsupported instructions report the failing address in error. |
